What is happening?

  1. Each point has coordinates (x₁, x₂) and a label (class 0 or 1). 80% are used for training, 20% for testing.
  2. The network is a stack of Dense layers. Each neuron computes activation(w·x + b).
  3. The last neuron uses a sigmoid to output a probability between 0 and 1.
  4. The loss (binary cross-entropy) measures how wrong the predictions are; the optimizer adjusts weights using backpropagation to reduce it.
  5. The background colour shows what the network predicts for every position, so you can see the learned decision boundary.

Things to try

  • Spiral with only x₁, x₂ and 1 layer: it fails. Add layers/neurons or extra features.
  • Set activation to linear: the network can only draw a straight line (no non-linearity).
  • Learning rate 1 vs 0.001: observe unstable vs slow training.
  • Increase noise and compare train vs test loss to see overfitting.
